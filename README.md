# 🌟 Liona's Portfolio Website

An elegant and interactive portfolio website showcasing my projects, skills, and professional background. Built with pure HTML, CSS, and JavaScript, this responsive portfolio features a charming star character that adds personality to the user experience while maintaining a clean, modern design.

---

## 📝 Project Overview

This portfolio website was designed and developed to present my work in an engaging and user-friendly manner. The site features a unique dark mode toggle, interactive popup windows, and a responsive design that works seamlessly across all devices.

**Key highlights include:**
- Interactive star character with facial expressions
- Smooth dark/light mode transitions
- Draggable popup windows for content display
- Mobile-first responsive design
- Pure CSS animations and transitions

---

## ✨ Features

### 🎯 Main Landing Page
- Clean, minimalist design with gradient buttons
- Animated star decoration with blinking eyes and smile interactions
- Responsive grid layout for project navigation
- Smooth hover effects and transitions

### 🌙 Dark Mode Toggle
- Interactive star click to toggle between light and dark themes
- Smooth color transitions for all UI elements
- Persistent mode preference using localStorage
- Custom dark mode color scheme with proper contrast

### 📂 Project Sections
- **About Me** - Personal introduction with decorative elements
- **Contact** - Professional contact information with direct email integration
- **CV** - Downloadable resume sections with preview functionality
- **Projects** - Interactive project cards with detailed popup views
- **Game** - Coming soon

### 🪟 Interactive Popups
- Draggable modal windows with custom headers
- Smooth opening/closing animations
- Z-index management for multiple open popups
- Escape key support for quick closing
- Responsive design for mobile devices

### 📱 Mobile Optimization
- Touch-friendly interface elements
- Landscape and portrait mode support
- Optimized typography and spacing for small screens
- Smooth scrolling and touch interactions
